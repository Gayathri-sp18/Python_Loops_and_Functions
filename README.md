## ✨ About This Project

This repository contains a beginner-friendly Python practice notebook focused on understanding fundamental programming concepts through simple and practical examples.

The notebook demonstrates how **loops and functions** can be used to build small interactive programs and solve basic programming problems.

---

## 🚀 What's Inside?

| 🔹 Topic          | 📝 Program           | 💡 Concept                       |
| ----------------- | -------------------- | -------------------------------- |
| 🎯 **While Loop** | Number Guessing Game | Repetition & User Input          |
| 🔢 **For Loop**   | Multiplication Table | Iteration & Range                |
| 🧮 **Functions**  | BMI Calculator       | Function Definition & Parameters |

---

## 🎯 Programs Included

### 1. 🎯 Number Guessing Game

A simple guessing game that demonstrates the use of a **while loop**.

The program repeatedly allows the user to enter a guess until the correct number is reached.

**Concepts covered:**

* `while` loop
* User input
* Conditional statements
* Repeated execution

---

### 2. 🔢 Multiplication Table

A multiplication table program demonstrating how a **for loop** can be used to repeat an operation for a specific range.

**Concepts covered:**

* `for` loop
* `range()`
* Iteration
* Basic arithmetic operations

---

### 3. 🧮 BMI Calculator

A simple BMI calculator demonstrating how to create and use a **Python function**.

**Concepts covered:**

* Function definition
* Parameters
* Return values
* Mathematical calculations
